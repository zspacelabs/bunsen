The residual sublayer is to the transformer what the residual unit is to the conv nets: the combinator that makes depth trainable. An encoder block is two of them in series, one around attention and one around the MLP. Most of the architectural changes between transformer families happen not in the branches but in the norms around them.

The slots

y = out( x + droppath( γ ⊙ post( f( pre(x) ) ) ) )

An empty slot is the identity. Every image family on this side fills only pre or only post, plus, sometimes, γ.

Norm kinds

Transformers normalize each token over its channels. Statistics never cross tokens or images, so these norms behave the same in training and inference at any batch size. That is the property BiT had to buy for conv nets with group norm.

  • LayerNorm{{cite:ba2016ln}}: subtract the token's mean, divide by its standard deviation, apply a per-channel affine. timm's ViTs use ε = 10⁻⁶. CLIP, Swin and the BEiT3 and AIMv2 towers keep PyTorch's 10⁻⁵. The ε is part of the weights' contract, which is why bunsen's policy carries it.
  • RMSNorm{{cite:zhang2019rms}}: divide by the root mean square, with no centering and no shift. It is cheaper and was popularized by language models. AIMv2 uses it everywhere: in the blocks, on the patch tokens and at the end.

Norm placement

  • Post-norm, LN(x + f(x)): the 2017 Transformer's{{cite:vaswani2017}}. The stream is renormalized after every add, so gradients to early layers pass through every norm. Deep post-norm stacks need a learning-rate warm-up to train at all{{cite:xiong2020}}. This is ResNet v1's activation-after-add.
  • Pre-norm, x + f(LN x): ViT and almost every vision transformer. The identity path is clean and the stack telescopes, which is ResNetV2's pre-activation law{{cite:he2016id}}. The price is that the stream's size grows with depth, since nothing renormalizes it. That is why a final norm sits after the stack.
  • Res-post-norm, x + LN(f x): Swin V2's{{cite:liu2022swinv2}}. The identity stays clean, and each branch's contribution is normalized before it is added, so no single block can inject a runaway activation. V2 introduced it after finding that the activations of large pre-norm Swins grew by orders of magnitude in deep layers. timm's rpn ViT tries the same placement on a ViT.

Filling pre and post together is the "sandwich" of some language models. No image family here uses it.

Layer scale

The conv nets had the same idea: initializing the last BN's γ in each residual unit to zero makes every unit start as the identity{{cite:goyal2017}}. Layer scale makes that gain an explicit per-channel parameter, separate from any norm, so it also works under pre-norm, where the branch ends in a linear projection rather than a norm.

Drop path

Stochastic depth carries over unchanged{{cite:huang2016}}. During training, each sublayer's residual is dropped for a whole sample with some probability, ramped linearly from 0 at the first block to the policy's rate at the last. Swin splits that ramp at its stage boundaries. It changes nothing at inference.
