The head turns the last stage's map into class logits. It has three parts: an optional final layer, a global pool, and a linear classifier with dropout before it.

The final layer

Which final layer a net needs depends on what its units leave unnormalized:

  • none: post-activation nets (ResNet, ResNeXt, RegNetX/Y). The last unit already ended with norm, add and act.
  • norm + act: pre-activation nets (ResNetV2, BiT). The residual stream has never been normalized, so it is normalized once before the pool{{cite:he2016id}}.
  • act: pre-activated or linear-output RegNets (V, Z). Their stream is unrectified.
  • 1×1 conv block: RegNetZ-h widens to 1536 features before pooling{{cite:dollar2021}}, the "head conv" of mobile designs.

Global pooling

Geometrically, the pool is the projection of a translation-equivariant feature field onto its translation-invariant part. Everything before it commutes with shifts (up to the aliasing discussed in downsampling), and everything after it ignores them.

The classifier

A single linear layer from pooled features to classes, with dropout before it during training. Re-heading a model for a new task replaces only this layer, which is why the pooled feature width (2048 for a ResNet-50) is the usual "feature dimension" of a backbone.
