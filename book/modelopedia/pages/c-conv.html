The conv block is the atom every other combinator is made from: a convolution, a normalization, and an activation, in that order. The families vary its four geometric parameters (kernel k, stride s, dilation d, groups g) and its two numerical options (weight standardization, SAME padding). They rarely touch anything else.

What a convolution is

A 2-d convolution is a linear map that commutes with translation. At each output position it applies the same Cout×Cin matrix to each of the k² neighbouring input vectors and sums the results:

y[p] = Σδ∈K Wδ · x[s·p + d·δ]

The four parameters change the geometry of the index set s·p + d·δ, not the algebra. k sets how many taps there are, d how far apart they are, s how coarsely the output grid samples the input, and g the sparsity of each Wδ.

A 1×1 conv (k = 1) has no spatial extent. It is a per-pixel linear map of channels, the "network in network" layer{{cite:lin2013nin}}. In a bottleneck the 1×1s change width and the one larger-kernel conv, the spatial mixer, is the only place where neighbouring pixels interact.

Groups and cardinality

A grouped conv splits the channels into g blocks and convolves each block separately. Its channel-mixing matrix is block-diagonal: a direct sum of g smaller convs.

Grouped convs only mix channels inside a group, so a grouped mixer has to be placed between dense 1×1s, which mix across groups. That is why the grouped mixer only appears inside bottleneck units.

Receptive field and dilation

A unit's reach on its input is d(k−1)+1. Stacking adds reach. Striding multiplies the reach of every later layer, measured in input pixels.

Output stride: trading stride for dilation

Classification wants a stride of 32. Dense prediction (segmentation, detection backbones) wants the last maps larger. The conv net's lowering supports an output stride of 32, 16 or 8: once the running stride reaches the target, any further stride becomes dilation, multiplied into every later unit. The first unit of such a stage takes the dilation from before the stage, and the others take the new one{{cite:chen2017deeplab}}.

Activations

Most of the lineage uses ReLU{{cite:nair2010}}. RegNetV and RegNetZ (timm's later designs) use SiLU, x·σ(x){{cite:elfwing2017,ramachandran2017}}, which is smooth and non-monotone near zero. EvoNorm-S0 brings its own SiLU-like activation (see Normalization). The activation is a layer choice made once for the net and inherited by every conv block and every unit's output.

Padding and weight standardization

Convs are padded to keep the size at stride 1, and the output side is ⌈H/s⌉. Two numerical options exist for weight compatibility. SAME padding pads each input from its own size (TensorFlow's rule, used by the hybrid ViT trunk). Weight standardization normalizes each output filter's weights to zero mean and unit variance before the conv{{cite:qiao2019}}. It is a reparametrization of the conv, not a new layer, and its geometry is covered with the norms (weight standardization), since it exists to pair with group norm.
