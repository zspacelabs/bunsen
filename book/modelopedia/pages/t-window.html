Window attention is Swin's token mixer{{cite:liu2021swin}}. It runs self-attention inside non-overlapping M×M windows of the token grid, so the cost is linear in the image's area. It shifts the windows by half a window in every second block, so information still crosses window borders. Positions enter as a learnt bias on each window's scores.

Windows, and shifting them

Two successive blocks thus have overlapping receptive fields, like two stacked 3×3 convs whose reach grows layer by layer. Window attention is a halfway point between a conv and global attention. It is local like a conv, but within a window the weights are content-dependent like attention's.

The grid clamps the window. When a stage's grid is no bigger than the window, the window shrinks to the grid and the shift is dropped. That stage's attention is then simply global. A Swin-T at 224 pixels has stage grids of 56, 28, 14 and 7. With M = 7, its last stage is one window: global attention with no shift. Swin-S3 uses this rule on purpose.

Relative position bias

Swin has no absolute position embedding. Each head adds B[Δ] to the score of a query–key pair with offset Δ, in the spirit of relative position representations{{cite:shaw2018}}. The bias depends only on the offset, so it is translation-invariant like a conv kernel. The paper found it worth more than an absolute embedding.

A learnt table, though, only knows the offsets it was trained on. Change the window and you have to interpolate the table. Swin V2's continuous position bias (CPB) replaces the table with an MLP (2 → 512 → heads, ReLU) evaluated at the offsets Δ̂ = sign(Δ)·log(1 + |Δ|), squashed to 16·σ(·){{cite:liu2022swinv2}}. The log spacing compresses large offsets, so a model fine-tuned at a larger window extrapolates over a shorter range. The offsets are normalized by the window the weights were pretrained at, so window12to24 means pretrained at 12 and run at 24.

Cosine attention

Dot-product scores grow with the size of the activations. In large Swins, a few heads came to be dominated by a few pairs of tokens. Cosine similarity is bounded whatever the activations' size, and together with res-post-norm it made V2's 3-billion-parameter models trainable{{cite:liu2022swinv2}}. V2's projections also bias the query and value but not the key.
