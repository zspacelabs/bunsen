Self-attention is the transformer's token mixer: the slot a 3×3 conv fills in a ResNet. Each token's output is a weighted mix of every token's value. Unlike a conv's kernel, the weights are computed from the content of the tokens{{cite:vaswani2017}}.

Multi-head self-attention

From the N×D tokens X, each head forms queries, keys and values by linear maps of width dh = D/h. It scores every query against every key, normalizes each row with a softmax, and mixes the values:

head(X) = softmax( Q Kᵀ / √dh ) V,   MHSA(X) = [head1 ‖ … ‖ headh] WO

The image encoders use the bidirectional form: every query sees every key, with no causal mask. Splitting into heads costs nothing extra (the h heads together have one D×3D projection) and lets the layer attend to h different patterns at once.

Attention versus convolution

Three consequences follow, and the later families exist to manage them:

  • No locality bias. Attention doesn't assume nearby pixels matter more. It has to learn that from data, which is why ViT needed very large datasets to beat ResNets{{cite:dosovitskiy2020}}, and why DeiT needed a heavy training recipe to do without them{{cite:touvron2021deit}}. Swin puts locality back with windows.
  • Permutation equivariance. Shuffle the tokens and the outputs shuffle the same way. All information about position comes from the position embedding.
  • Expressiveness. With relative position terms and enough heads, attention can reproduce a convolution{{cite:cordonnier2020}}. A conv is in that sense a constrained attention.

Cost

The projections cost 4ND², the same order as an MLP. The scores and mixing cost 2N²D, which is quadratic in the token count, so quartic in the image side at a fixed patch size. At 224 pixels in 16×16 patches (N = 196) the projections still dominate. At high resolution or with small patches the N² term takes over, and that is what window attention removes.

Biases and inner norms

A few knobs on the attention vary between families. None changes what attention computes, but each shows up in a family's circuit:

  • qkv bias: on by default. The MIIL weights, timm's GAP and res-post-norm baselines, and AIMv2 drop it. Swin V2 keeps biases on the query and value but not on the key (a key bias adds the same amount to every score in a row, and the softmax cancels it).
  • Output-projection bias: AIMv2, in the style of a language model, has no biases anywhere.
  • Sub-LN: BEiT3 normalizes the heads' concatenated output before WO, following Magneto's sub-LN for stable deep training{{cite:wang2022magneto}}. It is a norm placed inside the branch, separate from the sublayer's own norms.

QK-norm and the parallel and differential attention blocks of some recent timm ViTs are not in bunsen's ViT kit yet.
