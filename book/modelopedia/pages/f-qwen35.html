Qwen3.5 is a hybrid. Three layers in four replace attention with a gated DeltaNet, a linear-attention mixer with a fixed-size state, and the fourth is attention with an output gate. The design came to Qwen with Qwen3-Next{{cite:qwen2025next}}. Qwen3.5 uses it for its whole dense line, from 0.8B to 27B{{cite:qwen2026qwen35}}. In the algebra it is the first family with two different token mixers in one stack.

The hybrid stack

The stack is patterned with two kinds of layer, which share everything except the token mixer: the same 1 + w RMS norms, the same SwiGLU, the same residual layout. So the family needs two circuits, one per kind, and the second differs from the first only inside the token mixer.

The attention layer

Design change. Against Qwen3's layer: an elementwise sigmoid output gate before WO; RoPE on only the first quarter of each 256-wide head, with θ = 10⁷; 1 + w norms throughout; GQA of 4:1 to 6:1. QK-norm before RoPE, as in Qwen3.

Why. The gate removes attention sinks and adds a nonlinearity between the value and output projections{{cite:qiu2025}}. That matters more when attention is one layer in four and must make every head count. Partial rotary leaves most of each head free to match content at any distance, since the DeltaNet layers already carry order (partial rotary). The high base suits a 256K context.

The DeltaNet layer

Design change. The token mixer is a gated DeltaNet: four input projections, a 4-tap causal conv, L2-normalized queries and keys, the gated delta rule over a 128 × 128 state per value head, and a gated RMS norm. It has no rotary table, no softmax and no KV cache.

Why. A linear layer costs the same per token at any context length, and its state is a few hundred kilobytes however long the context. The delta rule makes that state an editable associative memory rather than a running sum, and the decay lets it forget (the rule). Three such layers to one attention layer cut the KV cache to a quarter, and keep exact retrieval in the attention layers.
