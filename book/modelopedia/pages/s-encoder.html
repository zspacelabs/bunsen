After the stem, an audio encoder is a stack of the same pre-norm residual layers as the language kits, built from the same DecoderStack with a different mask. What separates the recognizers' encoders is how they tell a layer where a frame is, and which frames it may see.

Positions

  • A learned table (Whisper): 1500 slots, one per 20 ms frame of a 30 s window, added once to the stem's output. Upstream fills it with sinusoids; bunsen loads it as a table, as the checkpoint stores it. A fixed table ties the encoder to its window: shorter audio is zero-padded to 30 s.
  • Sinusoids per chunk (Qwen3-ASR): a sinusoidal table that restarts every 1-second chunk, so position means "where in this second". Order across seconds is left to attention over the blocks.
  • Rotary (Voxtral Realtime): RoPE with θ = 10⁶ inside every attention layer, as in a decoder. Positions are relative, so the encoder can run over an unbounded stream.
  • Relative, additive (Parakeet): Transformer-XL's position term inside the score (the Conformer).

Masks

Whisper attends across its whole 30 s window. Qwen3-ASR attends within 8 s blocks (eight 1 s chunks), which bounds the cost of long audio and lets the blocks be processed independently. Voxtral's encoder is causal, with a 15 s sliding window, which is what lets the whole model stream with a fixed latency. Parakeet attends across each window it is given, up to 60 s at a time.

Whisper's missing key bias is harmless: a bias on the keys adds the same amount to every score in a query's row, which the softmax cancels. Voxtral's encoder is the one built like a modern decoder, RMSNorm and SwiGLU, and the only causal one.
