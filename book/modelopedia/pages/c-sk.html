The selective kernel lets each unit choose its receptive field per channel and per input{{cite:li2019sk}}. Two paths with different reach run in parallel, and an attention over their sum decides, channel by channel, how much of each to keep.

An input-dependent kernel size

The weights live on the segment Δ¹ (or a larger simplex with more paths). This is the same geometry as split attention, which keeps the operator and drops the different kernel sizes. With one path the operator would degenerate to SE.

Split input

With split_input each path reads its own half of the input channels instead of all of them, which halves the paths' cost. timm's basic SKNets (skresnet18/34) do this. The attention width is a fraction of the channels (⅛ for the basic nets, 1/16 for the bottleneck ones) rounded to a divisor.

In the algebra

SK is the one exotic mixer that also fits a basic unit: there it replaces the first 3×3, and in a bottleneck it replaces the 3×3. Each path is an ordinary conv block, grouped in SKResNeXt. DropBlock acts on the mixer's output.
