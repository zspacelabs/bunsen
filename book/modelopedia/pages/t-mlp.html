The MLP is the transformer's channel mixer. It is applied to each token alone: a widening linear map, a nonlinearity, and a narrowing map back. In conv terms it is a 1×1 bottleneck turned inside out: wide in the middle instead of narrow.

Kinds

The plain MLP is fc2(act(fc1 x)) with hidden width ⌊rD⌋. Because it acts on each token alone, it holds most of a ViT's parameters (about two thirds at r = 4) but does no mixing between tokens. A useful reading is that attention moves information between tokens and the MLP transforms it within each one.

Activations

  • GELU{{cite:hendrycks2016gelu}}: x·Φ(x), the default from ViT on.
  • QuickGELU: x·σ(1.702x), a sigmoid approximation used in OpenAI's CLIP weights{{cite:radford2021clip}}. Those weights only work with the activation they were trained with, so the _quickgelu names exist.
  • tanh-GELU: the tanh approximation of GELU, which some SigLIP towers keep{{cite:zhai2023siglip}}.

Gated MLPs: SwiGLU

A gated linear unit multiplies two projections of the input, one passed through an activation. With SiLU as the activation this is SwiGLU{{cite:shazeer2020glu}}:

SwiGLU(x) = fc2( SiLU(x Wg) ⊙ x Wx )

A gated MLP has three matrices instead of two, so its hidden width is usually shrunk to keep the parameter count. A ratio near ⅔ · 4 ≈ 2.67 matches a plain 4× MLP, and AIMv2 uses 2.75 and 2.67{{cite:fini2024aimv2}}. The multiplicative interaction lets each hidden unit act as a data-dependent gate, much as channel attention does in the conv half.

The packed form fuses Wg and Wx into one fc1 of twice the rows, split in halves after the projection. It is the same function in a different parameter layout. DINOv2's giant tower uses it with a nominal ratio of 5.33, so fc1 has 8192 rows and the gated hidden width is 4096{{cite:oquab2023dinov2}}.

Width ratios, and a norm inside

The ratio is a shape knob, not a design change. The "shape-optimized" SigLIP so400m tower (27 layers, width 1152, MLP ratio 3.74) came from fitting scaling laws over depth, width and MLP width{{cite:alabdulmohsin2023}}.

BEiT3 adds a LayerNorm on the hidden width before fc2: the MLP half of Magneto's sub-LN{{cite:wang2022magneto}}, matching the norm it puts inside the attention.
