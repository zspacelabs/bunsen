Qwen3.5's linear layers replace attention with a gated DeltaNet{{cite:yang2025}}: a recurrent token mixer with a fixed-size state, whose cost per token doesn't grow with the context. This chapter builds it up in three steps: linear attention, the delta rule, and the gate. Then it shows the block around the rule.

Attention without the softmax

Remove the softmax from causal attention, and the output at step t is Σs≤t vs (ksᵀ qt) = (Σs≤t vs ksᵀ) qt. The bracket is a dv × dk matrix that can be updated one outer product per token. So a linear-attention layer is a recurrent network, with constant cost per step{{cite:katharopoulos2020}}. Schlag et al. read the state as fast weights: a matrix the network writes associations into (key → value) and reads with queries{{cite:schlag2021}}.

Purely additive writes are the weakness. The state has room for about dk orthogonal keys. Past that, writes interfere, and writing a new value to an old key piles it on top of the old one rather than replacing it.

The gated delta rule

The delta rule writes the error instead of the value: read what the state currently returns for k, v̂ = Sᵀk, and move it toward v,

S ← S + β k (v − Sᵀk)ᵀ.

That is one step of online least-squares regression of values on keys: Widrow and Hoff's rule{{cite:widrow1960}}, applied to the fast-weight matrix{{cite:schlag2021}}. With |k| = 1 and β = 1 it overwrites k's value exactly. Yang et al. showed how to train it in parallel over the sequence, which made it practical at scale{{cite:yang2024}}. The gated DeltaNet adds a decay S ← eg S before each write. This is Mamba 2's forgetting{{cite:dao2024}}, and it lets the layer clear its memory quickly when the context changes{{cite:yang2025}}. Decay and delta are complementary: one erases everything a little, the other edits one association precisely.

In bunsen, GatedDeltaRule runs the rule in two forms. A decode step runs the four lines once. A prefill runs them 64 positions at a time in a parallel, chunked form. Both give the same result, so the length of a prefill never changes the output. The queries and keys are L2-normalized and the query scaled by 1/√dk, and the rule runs in f32 whatever the model's dtype.

The block around the rule

  • A short causal convolution (4 taps, depthwise) over the projected queries, keys and values, then SiLU. It mixes each token with its three predecessors before the rule sees it. That gives the layer cheap local order and n-gram features, and is why a DeltaNet layer needs no rotary table.
  • Write strength and decay from the input. β = σ(Wbx) per value head; g = −eA · softplus(Wax + dt), so the decay rate is learned per head and modulated per token.
  • More value heads than key heads. Qwen3.5 uses 16 key heads and 16 to 48 value heads, each 128 wide; the keys are repeated across value heads, the reverse of GQA. Each value head carries its own 128 × 128 state.
  • A gated output norm. w · RMSNorm(o) · SiLU(z), with z a fifth projection of the input: the DeltaNet's counterpart of the attention output gate.

The hybrid stack

A fixed-size state cannot recall an arbitrary token from far back, and attention can. So the hybrid keeps a few attention layers. With three DeltaNet layers to one attention layer, the KV cache is a quarter of a dense model's, and the per-token cost of three layers in four is constant. The design came to Qwen with Qwen3-Next{{cite:qwen2025next}}, and Qwen3.5 uses it at every size{{cite:qwen2026qwen35}}.

The state

A DeltaNet layer's decode state is its conv's last three inputs and its matrix S, kept in a DeltaNetState. Like a KV cache it is injected: the caller makes it and passes it in. Unlike a KV cache it cannot be rewound, since it summarizes its whole prefix. A decode that backtracks must snapshot it or start again (decoding state).
