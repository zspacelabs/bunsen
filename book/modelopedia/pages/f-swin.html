The Swin Transformer{{cite:liu2021swin}} brought the conv net's two structural priors back into the transformer. Locality returns as attention inside windows, and the pyramid returns as patch merges between stages. The result has a ResNet's shape (strides 4 to 32, widths doubling) with transformer blocks inside, and it took over the backbone role in detection and segmentation. bunsen builds it as the staged vision encoder.

Swin Transformer

Design. 4×4 patches embedded to width C (96, 128 or 192) and normalized. Four stages of depths [2, 2, 6, 2] (or [2, 2, 18, 2]) at widths C, 2C, 4C, 8C, each after the first opened by a 2×2 patch merge. Pre-norm blocks of window attention (M = 7, or 12 at 384 pixels), every second block with its windows shifted, a learnt relative position bias table, and a GELU MLP. Then a final LayerNorm, a mean pool and the classifier. There are no prefix tokens and no absolute position embedding.

Why. Global attention costs N², which rules out the high-resolution, multi-scale features dense prediction needs. Windows make the cost linear. Shifting them lets information propagate between windows, as stacked convs propagate it between neighbourhoods. Merges build the feature pyramid that FPN-style heads expect. Swin's case is that the transformer's gains came from attention as a mixer, not from giving up locality and hierarchy.

Slot fill. patch = 4×4 + LN · tokens = none · stack = 4 stages with merges (LN → 4C→2C) · mixer = shifted window attention with a relative bias table · pre-norm · final = LN · pool = avg.

Swin-S3: a window per stage

Design change. Each stage gets its own window size, found by architecture search: [7, 7, 14, 7] for Tiny and Base, [14, 14, 14, 7] for Small{{cite:chen2021s3}}.

Why. S3 searched the search space itself (depth, width, heads, MLP ratio, window) for vision transformers, rather than searching one fixed space. The windows it found are telling. Stage 3's window of 14 equals that stage's grid at 224 pixels, so the grid-clamp rule turns stage 3 into global attention: the search chose global mixing where most of the depth is. The early stages keep local windows, where the grid is large.

Swin Transformer V2

Design change. Three changes to the block and one to the merge:

  • Res-post-norm: x + LN(f(x)) in place of pre-norm.
  • Scaled cosine attention, with a learnt per-head scale capped at 100, and biases on the query and value only.
  • A continuous position bias: an MLP over log-spaced offsets, normalized by the window size the weights were pretrained at.
  • Merges reduce first and normalize after (4C → 2C → LN).

Why. V2 scaled Swin to 3B parameters and 1536-pixel images{{cite:liu2022swinv2}}. Two problems appeared. In large pre-norm models, activations in deep layers grew by orders of magnitude, and training diverged. Res-post-norm and cosine attention bound them. And models pretrained at small windows transferred poorly to the larger windows that high-resolution fine-tuning needs. The log-spaced CPB extrapolates where a table cannot. The names record that transfer: swinv2_base_window12to24_192to384 was pretrained at window 12 and 192 pixels, and runs at window 24 and 384. Its per-stage pretraining windows are [12, 12, 12, 6], because at 192 pixels the last stage's grid was only 6.
