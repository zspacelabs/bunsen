Attention is the token mixer of every kit but Qwen3.5's linear layers. It lets each position read a weighted mix of other positions, with weights computed from the content itself. bunsen builds every variant in this part from one module, CausalSelfAttention; what separates Qwen3's attention from Gemma 2's or ModernBERT's is config.

Scores, softmax, mixture

Each position projects its normalized state to a query q, a key k and a value v. The weights from query i to key j are a softmax over scaled dot products, and the output is the weighted sum of values{{cite:vaswani2017}}:

A = softmax(Q Kᵀ · s + M), y = A V, s = 1/√d

Two readings help. As a soft lookup, the query is a search key, the keys are an index, and the values are what is retrieved. As a data-dependent mixer, attention is a T×T mixing matrix computed fresh for each input, which is what separates it from a convolution's fixed taps. Multi-head attention runs H such maps in parallel, on H slices of width d, and an output projection WO writes their concatenation back to the stream.

Grouped-query attention

A decoder generating one token at a time must re-read every past key and value at every step. That makes decoding bound by memory bandwidth, not arithmetic{{cite:pope2022}}. Shazeer's multi-query attention (MQA) shares a single key and value head across all query heads, which cuts the cache by H×{{cite:shazeer2019}}. Grouped-query attention (GQA) interpolates: Hkv groups, each shared by H / Hkv query heads, recovering nearly all of full attention's quality at a fraction of its cache{{cite:ainslie2023}}.

The kits cover the whole range: nanochat and ModernBERT use full MHA; Qwen3 groups 2:1 at 0.6B and 4:1 at 4B and 8B; Gemma 2 groups 2:1; Gemma 1 2B and Gemma 3 1B are pure MQA (one key/value head); Qwen3.5 groups 4:1 to 6:1 in its attention layers.

Head width

By default a head is D / H wide. Several kits break that link and set the head width directly: Qwen3's heads are 128 wide at every size (16 × 128 = 2048 over a 1024-wide model), and every Gemma and Qwen3.5 attention head is 256 wide. WQ and WO then map between D and H·d. Wide heads give each head a higher-rank score map and more rotary frequencies; fixing d across sizes means a family's attention behaves alike from its smallest model to its largest.

The output gate

Qwen3.5's full-attention layers multiply the heads' concatenated output by σ(Wg x) before the output projection. The gate's weights live in WQ itself, which is twice as wide: each head's queries followed by its gates. Qiu et al. tested gates at every point in the attention block and found this one, elementwise after the values, the most effective{{cite:qiu2025}}. They give two reasons. The gate adds a nonlinearity between the value and output projections, which are otherwise one low-rank linear map. And it is input-dependent and sparse, so a head can switch itself off. Softmax weights must sum to one, so a head with nothing to say otherwise learns to dump its mass on the first token, the attention sink of streaming models{{cite:xiao2024}}; with the gate, sinks largely disappear. bunsen also supports a headwise gate (one scalar per head), which no language kit uses.
