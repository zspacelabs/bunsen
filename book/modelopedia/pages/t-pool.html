A conv net ends with a global average pool. A transformer has more options, because one of its tokens can be trained to be the summary. The pool and the norm next to it are the head-end slots of the transformer board. After them comes the same dropout → fc classifier as in the conv half.

Pool kinds

  • token: the class token's final state{{cite:dosovitskiy2020}}. The class token pools in every layer, by attending to the patches, so the "pool" is really spread over the whole depth.
  • avg (and max, avgmax): a reduction over the patch tokens, like a conv net's global pool. Swin, EVA, BEiT3, AIMv2, SigLIP's gap towers and timm's GAP ViTs use avg. Without a class token, the model saves one token and keeps the readout translation-invariant.
  • map: a multi-head attention pool, introduced for ViTs in Scaling Vision Transformers{{cite:zhai2022scaling}} and used by SigLIP. One learnt latent query attends over the patch tokens, then x + MLP(LN x). It is the only pool with parameters of its own.
  • distilled: DeiT's two-token head. The class token and the distillation token each go through their own classifier, and the two logits are averaged{{cite:touvron2021deit}}.

The attention pool, as a combinator

The map pool is the class token moved to the end. Instead of a query that takes part in every layer, there is one query that attends once to the finished tokens. It has its own h-head attention, its own norm and MLP, and the model's width and activation. The latent query is a set function: the order of the tokens doesn't change its output. bunsen builds it as LatentAttentionPool, from the same multi-head attention as the blocks.

Where the final norm goes

A pre-norm stack's stream is never normalized, so a norm has to come after the last block. There are three places it can go, and the circuits show it in FINAL NORM or POOL NORM:

  • Before the pool: every token is normalized, then pooled. This is the default for the token pool, and it is what Swin and SigLIP's gap towers do.
  • After the pool (timm's fc_norm): only the pooled vector is normalized. timm's default for the reducing pools, used by BEiT3, EVA, the res-post-norm ViT and most of timm's register GAP ViTs.
  • None: C-RADIO's towers have no final norm at all{{cite:ranzinger2024radio}}. What the last block emits goes straight to the pool.

The choice matters for transfer. With the norm before the pool, the patch tokens come out normalized for dense tasks. With the norm after the pool, only the global vector does.
